# 当前交付状态

本仓库从空仓库建立 Shadow Relay 源控制面，包含完整的持久化服务、中文界面、发布契约、配置模板和后续可运行的回归测试。

## 已实现

- Go API/Worker 单二进制、PostgreSQL 迁移与持久任务、独立加密快照目录。
- 协议识别、规范化、结构校验、差异，源审核、固定、回滚和失败隔离。
- 目录同步、候选接纳、忽略、永久屏蔽与指纹去重。
- 编排成员、过滤、主备优先级，独立 Provider 快照与传统聚合导出。
- 不可变版本、稳定指针、回滚、客户端格式权限与令牌生命周期。
- 外部运行时服务检测、状态读取、能力连接和原生后台入口。
- SSRF 出站边界、凭据加密、审核审计和脱敏反馈。
- 中文响应式管理页面、导入预览、编辑、版本详情、发布预览、QR 绑定。
- Docker/Compose 配方、开发入口、OpenAPI、JSON Schema 与设计/安全文档。

## 执行边界

本轮根据原始沟通新增：原生 Hub 插件转换/脚手架、relay-bridge、四阶段 live smoke、fixture 采集工具、自动发布门槛、独立体检周期、yuanc 目录、净化规则、新旧漫画仓、直播频道覆盖与 TXT/EPG 导出、播客制作、阅读深链、参考覆盖目录和本地内容版本更新。
