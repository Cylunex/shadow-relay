# 当前交付状态

本仓库从空仓库建立 Shadow Relay 源控制面，包含完整的持久化服务、中文界面、发布契约、配置模板和后续可运行的回归测试。

## 已实现

- Go API/Worker 单二进制、PostgreSQL 迁移与持久任务、独立加密快照目录。
- 协议识别、规范化、结构校验、差异，源审核、固定、回滚和失败隔离。
- 目录同步、候选接纳、忽略、永久屏蔽与指纹去重。
- 编排成员、过滤、主备优先级，独立 Provider 快照与传统聚合导出。
- 不可变版本、稳定指针、回滚、客户端格式权限与令牌生命周期。
- 外部运行时服务检测、状态读取、能力连接和原生后台入口。
- SSRF 出站边界、凭据加密、审核审计和脱敏反馈。
- 中文响应式管理页面、导入预览、编辑、版本详情、发布预览、QR 绑定。
- Docker/Compose 配方、开发入口、OpenAPI、JSON Schema 与设计/安全文档。

## 执行边界

不在本仓库实现 Shadow Media Android 托管模式、跨源内容搜索、视频代理、运行时规则引擎、自动安装扩展和听读联动。服务连接器的状态同步是 pull-only，功能深度以 `docs/adapters.md` 为准。没有进行服务部署或 APK 构建。

## 验证记录

实现过程中已完成过后端编译、Go vet、带竞态检查的真实 PostgreSQL 回归，以及前端构建和 API 单元测试。浏览器流程已执行到源导入、审核、启用、编排和发布；绑定表单测试暴露了标签定位问题，已改为显式 label/id 和 role 定位。

本提交保留独立源快照、相对链接规范化、脱敏反馈等后续改动，**最终提交尚未经过完整回归与浏览器复测**。新增测试已经写入仓库，CI 设置为手动触发或 PR 触发，普通推送不自动运行测试。

后续恢复验证时，按 `docs/development.md` 运行完整 Go/PostgreSQL 回归、前端构建和浏览器流程；Docker 配方尚未在本机实际构建。
