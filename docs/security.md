# 安全与恢复

## 凭据与访问

管理 API 使用独立随机 Bearer Token；浏览器只保存在当前页面内存，刷新需重新登录。API 不使用 Cookie，不开放 CORS；写操作需要 JSON，浏览器跨源写请求会被拒绝。部署到公网前必须使用 TLS 和受控入口，避免长期管理员令牌通过明文网络传递。

客户端令牌与管理员令牌完全独立。每个绑定的摘要、编排组、格式、有效期和代次在数据库中保存；原令牌只在创建与轮换时返回。服务不记录 HTTP 访问路径或 Authorization。反向代理同样应关闭 `/p/` 路径日志或脱敏 token 段；不要把包含令牌的 QR、截图和请求 trace 上传到公共服务。

请求头密钥使用 AES-256-GCM，并以 owner ID 作为附加认证数据，不能把另一条源的密文复制过来使用。秘密读取 API 仅返回头名称。原文快照单独加密，以内容哈希作为认证数据，临时写入、fsync 后原子重命名；目录 0700，文件 0600。

JSON 中显式的密码、Token、Cookie、Authorization、API key 等字段会被拒绝。URL userinfo、敏感 query 参数、控制字符、无效 query 被拒绝；凭据必须存入加密请求头。Opaque 规则只作为已审核数据，管理员仍须审查脚本中硬编码的凭据，不能把通用字符串扫描当作完整 DLP。

## 出站网络

唯一 HTTP 边界位于 `internal/fetch`：

- 只接受绝对 HTTP(S) URL，不继承进程的 HTTP_PROXY / HTTPS_PROXY，也不暴露任意代理配置。
- DNS 在实际 dial 时解析；所有 A/AAAA 都必须通过策略，直接拨号到已检查 IP，TLS 仍验证原 Host。
- 默认禁止环回、私网、链路本地、组播、共享地址、特殊保留段和常见 IPv4 转换地址。
- 访问受信 LAN 必须同时设置 trusted、trusted-lan 以及进程显式 CIDR 白名单；环回和元数据地址不可通过白名单开放。
- 每一跳重定向重新校验，跨 origin 清除所有自定义请求头，最多 5 跳；重定向目的 Host 也获取自己的并发额度。
- 每 Host 最多 2 个请求直到响应体关闭；连续网络/5xx 失败熔断 1 分钟。
- 有连接、TLS、响应头和整体超时；普通源最大 8 MiB、JSON API 有更小上限、媒体抽样 4 KiB。禁用自动压缩并拒绝压缩响应，避免解压炸弹。

对外订阅不执行网络拉取，不可充当任意 URL 代理。视频内容和外部执行器不经过 Relay Core。普通代码中没有 shell/JAR/JS/Python 执行入口。

## 边界与备份

数据库、快照目录、主密钥是一个恢复单元，应在受限位置一起备份。使用 PostgreSQL 一致性备份；快照不可变，可增量备份。备份包含实际服务地址和敏感配置，不能进入代码仓库。

恢复到隔离实例时先加载匹配的主密钥、快照和数据库，再运行迁移和 `/readyz` 检查，验证一条原文解密、客户端鉴权和最后发布版本。保存当前实例恢复点之后才切换入口。

- 内容更新异常：在源详情拒绝更新，或回滚到已批准版本并固定更新策略。
- 发布编排异常：回滚 Publication，只移动指针，不重写已有发布物。
- 单设备令牌泄漏：吊销该绑定或轮换令牌；旧令牌即使带旧 ETag 也不能获得 304。
- 管理员令牌泄漏：在受限配置中生成并替换管理员令牌，重启 API，再审计变更。
- 主密钥轮换：当前版本没有在线重加密工具；不得直接替换并丢弃旧密钥，先离线备份并制定重加密迁移。

运行时拥有自己独立的账号、内容缓存和沙箱。建议不挂载 Docker Socket，不共享 Relay 数据库凭据/主密钥，按域名约束出站，限制 CPU、内存与执行时长。这些执行器由其自己的部署配置落实，Relay 没有声称替外部服务创建隔离沙箱。
